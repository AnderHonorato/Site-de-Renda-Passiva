Perguntas frequentes

Preciso criar conta?

Não para usar as ferramentas públicas. A conta serve para sincronizar histórico, preferências e downloads entre aparelhos quando o backend estiver conectado.

Meus arquivos são enviados para algum servidor?

As ferramentas atuais foram projetadas para processar no navegador sempre que possível. Cada ferramenta deve informar quando um recurso exigir servidor.

Onde ficam os downloads?

No modo local, o portal registra apenas nome, ferramenta e data no seu navegador. Com conta conectada, o histórico poderá ser sincronizado via banco.

Como peço ajuda numa ferramenta?

Use o botão Ajuda no topo. O painel explica o fluxo básico e mostra atalhos para as categorias.
