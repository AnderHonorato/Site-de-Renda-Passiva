# Doce Ofício — Ferramentas úteis

Versão estática e funcional inspirada no layout multiplataforma anexado: fundo creme, terracota, verde sálvia, cartões de papel, tipografia artesanal e navegação responsiva.

## Ferramentas incluídas

- Orçamento doméstico
- Calculadora de tinta
- Planejador de festa
- Preço de venda para confeitaria
- Custo do artesanato
- Checklist personalizado
- Comparador de preço por unidade
- Custo de combustível
- Divisor de contas

## Como executar

Abra `index.html` em um navegador moderno. Não há dependências de build nem backend. Os cálculos são feitos localmente no navegador.

## Observações

Os resultados são estimativas e dependem dos dados informados. A fonte Google Fonts é opcional; se estiver indisponível, o navegador usa fontes de fallback. A pasta está pronta para receber posteriormente as demais ferramentas do catálogo e os blocos de anúncios, ainda não ativados.
