# Limite desta cópia GPT

O projeto ativo é `portal/`: um único site, 150 ferramentas, 15 categorias. Leia `prompt-mestre-orquestracao-codex.md` e `documentação/estado-execucao-gpt.md` antes de continuar.

Trabalhe exclusivamente nesta pasta `versões/GPT/Sites de Renda GPT`. O repositório Git aqui é independente. Não execute geradores, sincronizações ou builds na pasta original. As seis pastas copiadas são legado, não são o produto ativo.

O usuário autorizou iniciar o servidor do site original na porta 4311; isso não autoriza editar seu código. A versão GPT usa 4480 (desenvolvimento) e 4481 (pacote).

Use `npm test`, `npm run build`, `npm run dev`, `npm run preview`. Não publicar, comprar serviços, enviar mensagens ou fazer push sem instrução do proprietário. Não trocar modelos nem inventar revisões independentes. Manter processamento local, SVGs locais em vez de emojis, idioma português e validação real de arquivos.
